# 仿真实现与模型边界

以下说明逐项对应 `src/simulation/simulationEngine.ts`、`timeline.ts`、`vehicleConfig.ts`、`drivingCycles/index.ts` 和 `analysis/comparison.ts`。交付未修改这些文件。

## 1. 工况数据

样本格式为 `{ time: 秒, speed: km/h }`，至少两个点、首点时间 0、时间严格递增、速度非负且有限。六工况由少量关键点构成，目标车速在相邻点间线性插值；这是**目标轨迹插值**，不是对 SOC 等累计状态进行伪造插值。

| 工况 | 当前演示时长 |
| --- | ---: |
| CLTC | 300 s |
| NEDC | 315 s |
| WLTP | 270 s |
| FTP-75 | 240 s |
| US06 | 300 s |
| JC08 | 255 s |

源代码明确标注这些是近似演示轨迹，并非官方完整法规数据。当前没有 CSV 工况导入界面；注释中提到可扩展适配器不等于已实现导入功能。

## 2. 参数与初始化

展示车型 BYD ATTO 3。配置：电池 60.48 kWh、标称续航 460 km、质量 1750 kg、风阻系数 0.29、迎风面积 2.5 m²、滚阻系数 0.01、轮半径 0.33 m、传动比 9.1、传动效率 0.97、最大电机功率 150 kW、最大扭矩 310 N·m、最大回收功率 60 kW、辅助功率 0.7 kW、环境温度 25 °C。

初始状态：SOC 80%、电池能量 48.384 kWh、电压 398 V、电池温度 32 °C、预计续航 368 km、速度与累计里程/净能耗为零。代码中的车辆及热/效率参数为仿真假设，不可解释为完整官方标定。

## 3. 固定步长整车计算

`computeEVStep` 要求 `0 < dt <= 0.05 s`。`SimulationTimeline` 按 0.05 s 前进并缓存每个实际计算状态；每四步记录一条曲线样本。仿真完成于当前工况末端；目标速度函数本身周期化，但控制器不会在完成后自动重复工况。

在代码单位下，旧速度 `v` 与新速度 `v_next` 为 m/s：

```text
空气阻力 F_drag = 0.5 × rho × Cd × A × v²
滚动阻力 F_roll = m × g × Crr（车辆移动或目标速度非零时，否则为 0）
期望加速度 a_req = clamp((目标速度 - v) / dt, -3.5, 3.8)
期望纵向力 F_req = m × a_req + F_drag + F_roll
v_next = max(0, v + (实际纵向力 - 阻力) / m × dt)
```

正向驱动力在推进速度前受最大扭矩、功率和可用电池能量约束；负向力沿用期望制动力。实际速度因此不保证逐点等于目标速度。里程以新旧速度的梯形积分累计：`distance += (v + v_next) / 2 × dt / 1000`，单位 km。

没有坡度、轮胎滑移、多自由度车身、驾驶员 PID 或空气温度变化模型。

## 4. 电机与回收

```text
轮速 RPM = v_next / 轮半径 × 30 / π
电机 RPM = 轮速 RPM × 传动比
η = clamp(0.94 - 0.06 × |RPM/9000 - 0.55|
          - 0.04 × exp(-|纵向力|/800), 0.82, 0.95)
正向电机功率 = max(0, 纵向力) × v_next / 传动效率 / 1000
```

效率是 82–95% 的平滑经验包络，没有真实效率 MAP。驱动扭矩由功率与转速关系求取；零转速正向力时使用轮侧力换算。

负向力且新速度大于零时计算回收：

```text
机械可回收功率 = -纵向力 × v_next × 传动效率 / 1000
满电衰减 = clamp((100 - SOC)/5, 0, 1)
低速衰减 = clamp(v_next/3, 0, 1)
回收电功率 = -min(机械可回收功率 × η, 最大回收功率,
                   最大扭矩 × RPM × π / 30000 × η)
                × 满电衰减 × 低速衰减
回收时电机功率 = 回收电功率 / η
```

回收功率采用负号。可能有制动但没有有效回收；辅助负载也可能使电池仍净放电。显示层使用已有功率及状态，不另算一套能量。

## 5. 电池、SOC、能耗与续航

```text
电池功率 P_bat = (驱动时 电机功率/η；回收时 回收电功率) + 辅助功率
电池能量 E_next = clamp(E - P_bat × dt / 3600, 0, 电池容量)
SOC = E_next / 电池容量 × 100
电压 U = 350 + 0.6 × SOC
电流 I = P_bat × 1000 / U
累计净能耗 += P_bat × dt / 3600
预计续航 = SOC / 100 × 标称续航
```

电池功率还被限制在本步可放电/可充电能量范围；空电池不继续消耗不可用能量。正电池功率表示消耗，负值表示净充电。电压仅为 SOC 的线性近似，没有内阻、OCV 曲线、电芯不均衡或老化模型。

瞬时百公里能耗：速度 >= 3 km/h 时为 `P_bat / speed × 100`，低速显示不可用。平均百公里能耗：累计里程 >= 0.01 km 时为 `净能耗 / 里程 × 100`。预计续航未使用当前工况能耗进行预测。

电池温度是经验集中参数模型：

```text
T_next = T + (P_bat² × 0.000008 - (T - 环境温度) × 0.0008) × dt
```

该系数不是经过实车验证的电化学/热管理标定。

## 6. 控制、缓存与对比

- 倍速档位改变每次刷新消化的固定计算步数量，不放大 dt。
- 一键完成与未计算时刻定位按约 8 ms 分片，期间让出浏览器主线程。
- 回看从 0.05 s 状态缓存取值；时间轴按此步长定位，不线性插值 SOC。
- 切换工况重新计时但保留电池、温度与累计行程；重置恢复默认初始条件。
- 对比分析每个工况分别新建初始状态和时间轴，不共享电池消耗。
- 单工况结果里程及净能耗为终态与该时间轴初态之差。百公里能耗按该工况实际里程归一化；不足 0.01 km 为不可用。
- 平均车速 = 实际里程 × 3600 / 时长；最高车速来自固定步计算状态。
- SOC 消耗 = 初始 SOC - 终点 SOC，单位是百分点，不是相对下降百分比。
- 累计回收能量 = 对 `max(0, -regenPower) × dt / 3600` 的积分，未扣辅助负载；净电池能耗已扣回收，不能再次重复扣除。

## 7. 规则总结与验证边界

总结需要至少两个有效百公里能耗结果；动态排序得到最低/最高工况，报告绝对差值及以最低正值为基准的相对差。绝对差 < 0.1 kWh/100km 或相对差 < 2% 时提示差异较小。特征还引用实际平均车速与累计回收数据。不按工况名称预定排名，不将相关性称为因果。

已有单元测试检查固定步、能量关系、控制及独立对比等软件行为；通过测试不等于实车或法规认证。实测交付验证见 `VERIFICATION.md`，模型精度、完整法规轨迹和硬件蓝牙均不在本次认证范围。
