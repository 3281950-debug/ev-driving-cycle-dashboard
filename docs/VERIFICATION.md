自动化流程中，CLTC 初始一键完成从点击前到结果出现约 27 ms；六工况分析从点击返回到完成反馈的等待约 85 ms。两者测量起点不同，包含浏览器自动化及渲染等待，不是纯算法基准，也不是其他电脑的性能承诺。完整记录见 docs/evidence/browser-results.json。

## 限制和未验证项

- 未在另一台全新电脑或 Windows 10/11 虚拟机实测；PATH 隔离与换目录测试不能替代目标机认证。
- 外网请求阻止测试已通过，但没有拔网线或禁用系统网卡；浏览器及本地回环服务仍正常使用。
- 未做长时间内存压力测试、所有浏览器版本认证或实际 125% 缩放验收。
- 未测试实车蓝牙、硬件驱动及不同单位的脚本安全策略。
- 没有数据导入 UI，不能把导出通过解释为导入通过。
- 工况为近似演示数据；模型不是实车标定，结果不是法规或因果认证。
- npm 安装提示部分原有开发工具包已弃用；本任务保留锁文件及原工具链，没有擅自升级。这些包不作为 Portable 的启动依赖。
- 仿真及分析结果刷新即清空；需要保留时先导出 CSV。
